SAATHI AI - Android starter project

Is project mein:
- Microphone speech recognition
- Text-to-speech response
- Installed apps ko naam se open karna (e.g. "Open YouTube")
- Gemini AI chat ka optional connection

Android Studio mein chalane ka tareeqa:
1. ZIP extract karein.
2. Android Studio mein 'Open' karke SaathiAI folder select karein.
3. Gradle sync complete hone dein.
4. MainActivity.kt mein apiKey ki jagah apni Gemini API key lagayein.
5. Phone USB debugging ke zariye connect karein aur Run dabayein.
6. Pehli dafa microphone permission Allow karein.

Zaroori:
- API key ko public GitHub repository mein upload na karein.
- Ye starter source project hai, compiled APK nahi.
- AI chat ke liye internet aur valid Gemini API key chahiye.
- App launch karna Android ki installed-app availability aur phone restrictions par depend karta hai.
